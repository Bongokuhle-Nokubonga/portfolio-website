# Portfolio Website

My personal portfolio site: about me, skills, experience, projects and certifications.

Built with plain **HTML, CSS and JavaScript** (no frameworks). It works on phones,
has a dark mode, and is hosted free on **GitHub Pages**.

**Live site:** https://bongokuhle-nokubonga.github.io/portfolio-website/

## Features

- Responsive layout with a mobile menu
- Light and dark mode that remembers your choice
- Animated stats and fade-in sections (turned off for people who prefer reduced motion)
- Project links come from one setting (`GITHUB_USERNAME` in `script.js`)

## Run locally

Open `index.html` in a browser. That's it.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository called `portfolio-website`
2. On GitHub, open **Settings → Pages**
3. Under **Source** choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then click **Save**
4. After a minute the site is live at the address above
